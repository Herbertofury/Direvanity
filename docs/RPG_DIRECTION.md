# Direvanity: single-player RPG direction

Accepted direction: 25 November 2026, America/Denver.

The primary game is a massive character-led single-player action RPG. The player creates a character,
chooses a class, explores an interconnected world, talks to people, makes quest decisions, discovers
secrets and dungeons, develops a build, and completes an authored campaign. The existing RTS skirmish
remains an optional engine regression scenario. Army recruitment is not the required campaign loop.

The original Divine Divinity (2002) is a central world and role-playing reference. Diablo's full series
informs class identities, combat, itemization and skill trees. Lost Ark informs control, animation,
skill expression and boss readability. Path of Exile and Path of Exile II remain build-system and
combat references. The campaign must work offline and be completable solo, with pause and local saves.

## Acceptance ledger

- [x] Source-backed full class and ability research with per-game coverage counts and unresolved gaps.
- [x] Original Divine Divinity reimplementation/source-port findings verified against primary projects.
- [x] Character creator with unrestricted class/body pairing, name, appearance and persistent identity.
- [x] All verified distinct Diablo class identities available in the design roster, including legacy classes.
- [x] A coherent skill architecture combining related effects without erasing class identities.
- [x] Playable single-character campaign foundation using the authoritative Rust simulation.
- [x] A world/campaign/quest/loot roadmap with implemented content separated from production ambition.
- [x] Verified builds, actual runtime paths, public source checkpoint and published RPG packages.

**Complete backup delivery is a required final gate.** The full clean-source checkpoint must pass
independent payload verification and complete-file download/readback before delivery is considered
complete. The release asset `Direvanity-delivery.json` records that post-transfer result and exact
archive identity; it is written after the transfer so the archive does not contain a claim about its
own future upload. See [STATUS.md](STATUS.md).

## Quality destination

The production destination remains AAAA ambition. Large scope must mean authored locations, quests,
encounters, character progression and systemic depth, not only a large map or a long feature list.
High-fidelity original characters, animation, audio, cinematic dialogue, controller support, robust
navigation, accessibility and measured hardware performance remain explicit production gates.
